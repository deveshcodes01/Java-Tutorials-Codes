1. WHAT IS TWO POINTERS?
===============================================================================

Instead of using one pointer to scan the array,

we use TWO pointers.

Depending on the problem,

they can

• Move towards each other

        left ---------> <--------- right

OR

• Move in the same direction

        left ------>
                right ------>

This reduces many O(n²) solutions to O(n).

6. MENTAL MODEL
===============================================================================

Imagine two people standing at opposite ends of a road.

They keep walking.

Every step removes one possibility.

Instead of checking

N² pairs,

they eliminate impossible pairs.

===============================================================================
7. EXAMPLE 1
Two Sum II
===============================================================================

Array

1 2 3 4 6 8 10

Target = 10

left = 1

right = 10

Sum = 11

Too large

Move right

-----------------------

left = 1

right = 8

Sum = 9

Too small

Move left

-----------------------

left = 2

right = 8

Sum = 10

Found.

===============================================================================
Java Code
===============================================================================

class Solution {

    public int[] twoSum(int[] numbers, int target) {

        int left = 0;
        int right = numbers.length - 1;

        while(left < right){

            int sum = numbers[left] + numbers[right];

            if(sum == target){

                return new int[]{
                        left + 1,
                        right + 1
                };
            }

            if(sum < target){

                left++;

            }else{

                right--;
            }
        }

        return new int[]{-1,-1};
    }
}

Time

O(n)

Space

O(1)

Move Zeroes

int left = 0;

for(int right=0; right<n; right++){

    if(nums[right]!=0){

        swap(nums,left,right);

        left++;
    }
}
