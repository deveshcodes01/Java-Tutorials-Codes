1. WHAT IS VARIABLE SLIDING WINDOW?
===============================================================================

Unlike Fixed Window,

the window SIZE CHANGES.

Sometimes it expands.

Sometimes it shrinks.

Example

Expand

A B C D

Shrink

B C D

Expand

B C D E

Window size is NOT fixed.

4. UNIVERSAL TEMPLATE
===============================================================================

int left=0;

for(int right=0;right<n;right++){

    // include nums[right]

    while(window is invalid){

        // remove nums[left]

        left++;
    }

    answer=Math.max(answer,
                    right-left+1);
}

7. JAVA TEMPLATE USING HASHMAP
===============================================================================

HashMap<Character,Integer> map=new HashMap<>();

int left=0;

for(int right=0;right<s.length();right++){

    map.put(s.charAt(right),
            map.getOrDefault(s.charAt(right),0)+1);

    while(window invalid){

        map.put(s.charAt(left),
                map.get(s.charAt(left))-1);

        if(map.get(s.charAt(left))==0)

            map.remove(s.charAt(left));

        left++;
    }

    answer=Math.max(answer,
                    right-left+1);
}

8. HOW TO DECIDE WINDOW INVALID?
===============================================================================

Depends on the problem.

Examples

Longest Unique Substring

Duplicate exists

--------------------------------

At Most K Distinct

Distinct > K

--------------------------------

Character Replacement

Replacement Needed > K

--------------------------------

Max Consecutive Ones

Zeros > K

Each problem changes ONLY this condition.

Everything else remains almost identical.

❌ Updating answer before shrinking
